# Java Developer Intern Projects

This bundle contains two starter projects built with Java 17 and Spring Boot.

## Projects
1. `employee-management-system` — web-based employee CRUD application using Thymeleaf and H2.
2. `expense-tracker` — expense CRUD application with REST API, category filtering and spending summary.

## Run either project
Open a terminal in that project's folder and run:
```bash
mvn spring-boot:run
```
Employee Management System: http://localhost:8080  
Expense Tracker: http://localhost:8081

Each project has its own README with features and API instructions. These are starter implementations; run and test them locally before submitting them for evaluation.
